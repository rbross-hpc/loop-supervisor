# Objective

Describe what you want built. This file is read first by every
loop-supervisor agent role (planner, architect, builder, auditor), so
be concrete about scope and priorities.

Replace this with your project's actual objective before starting a
run. For example:

- What should exist when this project is "done" (or what is the
  standing priority if it never truly is)?
- What should the loop work on first?
- Anything explicitly out of scope, so the planner doesn't wander into
  it?

Update this file at any time to redirect an in-progress loop; the
planner reads it fresh on every invocation, so no restart is required.
